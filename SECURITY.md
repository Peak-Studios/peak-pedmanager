# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in `peak-pedmanager` (such as SQL injection, unauthenticated net event triggers, or NUI exploits), please report it directly via Discord to Peak Studios leadership rather than opening a public issue.

We aim to acknowledge reports within 48 hours and release fixes promptly.
